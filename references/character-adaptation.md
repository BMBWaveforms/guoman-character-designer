# 年龄、性别与世界观的适配规则

## 美术风格不变，人物表现改变

固定的“3D半写实国漫+BJD人偶风”是美术媒介与面部造型精度，不是规定所有角色都长得像20岁偶像。可以保留风格化CG皮肤材质，同时描写皱纹、疲态、雀斑、痣、疤痕、不同肤色和体型。

| 人物 | 身体/面部 | 服装重点 | 不得误套用 |
|---|---|---|---|
| 幼童/儿童 | 年龄合理的头身比例，柔和面部轮廓与动作姿态 | 舒适安全、符合时代年龄的层次 | 九头身、220cm、成人面部结构、成熟妆容 |
| 青少年 | 生长期比例，青春期五官与形体 | 校服、便装或世界观服饰 | 不必要的成年化和成人服饰 |
| 青年成人 | 按设定高挑/矮壮/健美/普通等自由变化 | 服装细节可以丰富 | 一律纤瘦、冷白皮、短碎发 |
| 中年人 | 明确年龄线索和骨相，可有胡须、皱纹、成熟体态 | 职业、阶层与生活痕迹 | 机械抹平法令纹、胡须、肌肉 |
| 老年人 | 年龄感明显但保持精致CG塑形；白发、皱纹、斑纹可以有 | 服装体现时代及身份资历 | “无皱纹”“无毛孔”式一刀切否定老态 |

## 世界观对应的服装语言

- **中国古代/架空古风**：里衣、中衣、交领/圆领/立领、外袍、护肩/甲片、腰封、束带、绣纹、织金、锦缎/棉麻/皮革、云纹/山水纹、软靴/长靴、发冠/簪、佩玉、武器。按人物身份选择，不无缘无故加入现代运动鞋和耳机。
- **现代都市**：针织、棉质、丹宁、羊毛、皮革、尼龙、羊绒、金属配件等；外套、衬衫、T恤、卫衣、西装、裙装、鞋履与配件必须具有可见版型。
- **近未来/科幻**：技术织物、耐磨分区、功能裁片、磁吸扣、护甲模块、柔性护颈、发光指示线、可拆卸装备等；仍应保持有物理逻辑的穿戴结构和克制的识别性设计。
- **架空奇幻**：可以加入非现实的纹样、饰品和魔法装备，但面部四视图与服装前后结构仍然要有连续性。

## 常见冲突的处理

1. “80岁、白须长者” → 不写“避免皱纹、胡须、老人感”；可写“避免脸部塑料质感、年轻化五官”。
2. “健硕的女战士” → 不写“避免肌肉壮汉”或强制细肩细腰；明确健壮却有审美整体感。
3. “7岁儿童” → 不追求九头身与强骨相；避免成人化妆容和服饰。
4. “高科技盔甲骑士” → 层次描写应转向装甲板连接、内衬、关节活动空间、表面涂层与磨损，而不是强制写西装、卫衣、裤口袋。
5. “高领遮耳头盔/蒙面” → 对本 Skill 默认四视图大幅面部特写有冲突时，明确头盔/遮挡部件在特写中如何展示，使观者仍可辨认人物五官；优先保证身份展示与服装一致，不随意换装。

## 负面词生成规律

以“避免真人摄影质感、过度真实皮肤毛孔、廉价塑胶感、五官变形、人物不一致、肢体错误、鞋履被裁切、文字、标识与水印”等**画面技术瑕疵**为通用起点；再根据角色添加禁项，如“避免服饰时代错乱、盔甲结构断裂、配饰正反面不一致”。

禁止将用户指定的年龄、性别特征、体型、肤色、胡须、疤痕、妆容、纹身或服装纹样写成负面词。
