# 手动验收输入与检查要点

测试时将以下任一文字输入交给 Skill，检查最终输出是否为**一整段、无解释、无标题**的中文四视图生图提示词。

1. “17岁唐风少女，乌黑长发，活泼灵动，湖蓝色襦裙。”：年龄合理、不成年化；襦裙结构、面料、纹样、发饰；四视图一致。
2. “70岁古代男方士，瘦高，花白长髯，墨绿色长袍。”：显著年龄感与长髯；负面词不能出现“避免胡须、皱纹、老态”。
3. “9岁近未来女童，亚麻金短发，佩戴单侧通讯耳机，橙色防护服。”：儿童比例；未来防护服结构；耳机位置跨视图一致。
4. “43岁男性废土机械师，皮肤黝黑，肌肉结实，左眉有一道疤。”：肤色、疤痕和体格保留；负面词不能禁止疤痕、肌肉和深色皮肤。
5. “28岁古风女剑客，黑色高马尾，穿月白色练功服，佩长剑。”：高马尾与剑悬挂位置明确，侧背视图一致。
6. “现代都市男大学生，宽松针织风，暖棕色碎发。”：缺少年龄等信息时自行补全；服装写出层级、具体版型、面料和鞋履，不追问。
